# Cesium CFD 风场流体仿真 Demo

这是一个基于 **Cesium + Canvas 粒子平流** 的轻量 CFD 风场可视化示例：

- 在中国近海区域构造了一个二维速度场（旋涡 + 急流 + 剪切扰动）；
- 通过粒子在速度场中的平流运动，模拟风场流体流动效果；
- 提供粒子数、速度系数、尾迹衰减等实时参数控制。

## 快速运行

```bash
python3 -m http.server 8000
```

打开浏览器访问：`http://localhost:8000`

## 文件说明

- `index.html`：页面结构与 Cesium 容器；
- `main.js`：风场构造、插值采样、粒子仿真与渲染；
- `styles.css`：界面样式与叠加层控制。

## 说明

该 Demo 使用程序合成风场，不依赖外部 CFD 数据文件，便于快速理解 Cesium 中风场流体动画的核心实现思路。
